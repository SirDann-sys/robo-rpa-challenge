Robô RPA Challenge

Um robô preenche o mesmo formulário dez vezes, e a cada rodada os campos trocam de lugar. Esta página não é simulação: é o replay da última execução real, feita pelo GitHub Actions num Chrome sem janela, com os prints que o próprio robô tirou.

      Como funciona

      • Acha cada campo pelo rótulo, nunca pela posição: //label[normalize-space()='Email']/following-sibling::input.
      • Corrige a planilha: o cabeçalho "Last Name " tem espaço sobrando e o telefone vem como número (40716543298.0).
      • Roda sozinho no GitHub Actions a cada mudança no código e todo dia: instala o Python, roda os testes, executa o robô e publica esta página. Se o robô falhar, a página não é trocada.
      • Pronto para o BotCity Maestro: lá ele envia o print como artefato e fecha a tarefa com o resultado.

      Os prints de cada rodada deixam a execução gravada alguns segundos mais lenta do que a normal.
